Changed: the HTML cache request check accepts an `X-Original-URL` header whose every value equals the request target the page is keyed on, byte for byte, as IIS URL Rewrite sends on a rewritten request, so such requests are stored and answered from the HTML cache. Any other value (another path or query, a case or percent-encoding difference, a second value that differs, or the `X_Original_URL` spelling) is still refused.
