Added: C API 1.15 for serving cached HTML from a front end's own HTML store. The serve request gains a serve scope (known agents or everyone), an agent class, an operator cap on a served page's age (it only ever shortens the origin's lifetime), fresh-only serving with no validation step, an HTML fallback after a Markdown miss, a conditional-request bit and the stamp of the credentialed policy in force. New pure entry points sort a request's Cookie lines into none, ignorable-only or blocking against a built-in analytics ignore list (session cookies are never ignorable), check an operator's ignore-list addition at configuration load, compute the policy stamp, refuse requests carrying unkeyed forwarding, method-override or AJAX headers and cache-deception paths before any read, and say whether an unsafe method's response invalidates the stored page. Stored pages record whether they came from an anonymous request and under which policy, in a new header block format that also keeps the origin's Cache-Control and Expires lines verbatim.
