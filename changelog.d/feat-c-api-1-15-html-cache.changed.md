Changed: with a 1.15 library the HTML cache is stricter for cookie-bearing requests in every serve mode. A request with a cookie outside the ignore list is neither stored nor answered from the cache unless the operator chose the explicit-public policy and the response is explicitly shareable; before, an explicitly shareable response was stored for any cookie. Every page stored before the upgrade is fetched from the origin once and recorded again, for HTML and Markdown alike. A library downgrade reads the new header blocks as missing; purge the site after a downgrade.
