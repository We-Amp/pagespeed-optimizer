Changed: with a 1.15 library the HTML cache is stricter for cookie-bearing requests in every serve mode. A request with a cookie outside the ignore list is neither stored nor answered from the cache unless the operator chose the explicit-public policy and the response is explicitly shareable; before, an explicitly shareable response was stored for any cookie. These rules need the 1.15 library in every serve mode: with an older library a front end gets the earlier cookie rule. Every page stored before the upgrade is not answered from the cache, for HTML and Markdown alike, until it is recorded again; with an earlier module that keeps an unchanged page until its re-store is due, that can take up to half the page's lifetime. A library downgrade reads the new header blocks as missing; purge the site after a downgrade.
