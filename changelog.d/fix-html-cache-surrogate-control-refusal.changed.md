Changed: the HTML cache store policy now reads `Surrogate-Control` and `CDN-Cache-Control` (RFC 9213). A response whose line in either carries `private` or `no-store` is refused as `private` or `no_store`, with the line name as the detail, so the cacheability report names the real reason instead of an uncarried header. Other values of these lines do not change the stored lifetime; a response carrying either line is still not stored.
