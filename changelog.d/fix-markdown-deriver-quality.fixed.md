Fixed: the Markdown copy of an HTML page is more faithful to the page. It is now always valid UTF-8 (a literal no-break space no longer leaves half of its encoding behind, and bytes that are not UTF-8 become U+FFFD). It keeps a `<header>` inside `<main>`, `<article>`, `<section>` or `<aside>`, so a page whose H1 sits in such a header keeps its H1. Multi-line commands keep their line breaks: a multi-line `<code>` that starts its own block becomes a fenced code block, a `<br>` inside `<pre>` is a line break, and a `<pre>` that renders one `<div>` per line stays one fence; fences are always longer than any backtick run in the code. Every named character reference of the HTML Standard and every numeric reference is decoded, also in text that mixes them with literal UTF-8 and in the front-matter title and description, and an unknown reference no longer stops the rest of the text from being decoded. Text the page shows as markup, such as `&lt;img&gt;`, stays an escaped literal (`\<img>`) that no Markdown renderer turns into a tag. Link labels and inline code are trimmed, a `<br>` inside a heading keeps the heading on one line, content marked `data-pagefind-ignore` is left out, and card links (a link wrapping a heading and a description) are one link each, kept apart. The deriver version is raised, so a page whose copy was withheld under the previous deriver is derived again; a copy already stored is replaced when the page changes or is purged.
