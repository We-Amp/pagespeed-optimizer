Changed: the ids 0xDC and 0xEC now hold the compressed Markdown copies; they were free for an embedder to use before. `ps_cache_write_sentinel` refuses both, and an exact-id read of either returns not-found for an entry the optimizer did not write, so data an embedder stored there with an earlier library is no longer readable and may be replaced. From C API 1.16 the public header needs a C11 (or C++) compiler.
